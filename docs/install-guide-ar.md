# تثبيت واستخدام vAntah

vAntah واجهة سطح مكتب أصلية للينكس. ليست نظام Apple. تستخدم GTK للنوافذ وKWin للتمويه والانكسار الفوري. الإعدادات والملفات يدعمان التبديل بين الإنجليزية والعربية مع اتجاه من اليمين إلى اليسار. تحتفظ البرامج الأخرى بلغاتها وإعدادات لوحة المفاتيح الخاصة بها.

## الطرق المتاحة

- **تحديث حاوية Alpine الموجودة:** تم اختباره على حاوية المشروع بمعمارية ARM64، مع الحفاظ على ملفات المستخدم.
- **بناء حاوية جديدة:** توجد ملفات البناء، لكن لم يُعاد اختبار بناء نظيف لهذا التحديث بعد.
- **حاسوب قديم يعمل بلينكس وDocker:** يمكن تجربة طريقة الحاوية في المتصفح. لم تُختبر أجهزة x86_64 أو الأجهزة الفعلية هنا.
- **استبدال النظام المثبت على القرص:** لا يوفر المشروع مُثبّت نظام أو سطح مكتب أصليًا لهذه الطريقة.

الجلسة التي اختُبرت تستخدم نواتين افتراضيتين وذاكرة 2 GiB ودقة 1280×768 ورسوميات Mesa برمجية. بناء KWin يحتاج عدة جيجابايت من أدوات التطوير. يُفضّل توفير نحو 20 GB مساحة فارغة وذاكرة 4 GiB أو أكثر للبناء الأول. هذه تقديرات عملية وليست متطلبات دنيا مُقاسة. قد تكون مؤثرات الزجاج بطيئة على الأجهزة القديمة.

## التحضير

ثبّت Docker وGit وcurl، ثم تأكد من عمل محرك لينكس:

```sh
docker info
git --version
```

## تجربة النسخة الحالية بأمر واحد

```sh
curl -fsSL https://raw.githubusercontent.com/Up-to-code/vantah/main/try-current.sh | sh
```

ينزّل الأمر المصدر العام ويبني KWin والمؤثرات المثبتة بإصدارات محددة، ثم يبدأ حاوية `vantah-current`. البناء الأول قد يستغرق وقتًا طويلًا. هذه طريقة بناء من المصدر وليست صورة جاهزة. افتح الرابط الذي يطبعه الأمر، عادة:

<http://127.0.0.1:6081/vnc.html?autoconnect=true&resize=scale>

المنفذ محلي فقط، ولا تُربط مجلدات الحاسوب بالحاوية. عند تكرار الأمر تُشغّل الحاوية نفسها دون استبدال ملفاتها. المُثبّت القديم `v0.1.1/try.sh` يشغّل نسخة Picom التاريخية؛ استخدم `main/try-current.sh` لهذا التحديث.

## تحديث حاوية المشروع الموجودة

```sh
git clone https://github.com/Up-to-code/vantah.git
cd vantah
sh install.sh alpine-gui
```

غيّر `alpine-gui` إلى اسم حاوية المشروع لديك. يُحدّث الأمر المصدر والمظهر ويعيد تشغيل الحاوية دون حذف ملفات المنزل. يفترض بنية حاوية المشروع ومستخدمًا برقم 1000؛ لا تستخدمه مُثبّتًا عامًا لأي نظام. إذا كان KWin المطلوب غير موجود، سيُبنى من المصدر.

## الاستخدام

1. افتح **الإعدادات ← اللغة** واختر العربية. تُعكس القوائم الجانبية وعناصر التحكم، مع إبقاء مسارات الملفات من اليسار إلى اليمين. هذا لا يضيف تخطيط لوحة مفاتيح عربية تلقائيًا.
2. في **المظهر** غيّر الوضع الداكن وتقليل الحركة ودرجة تلوين الزجاج. ينتج KWin التمويه والانكسار؛ يزيد التلوين وضوح النص فوق الخلفيات المزدحمة.
3. افتح **الملفات** من شريط التطبيقات. تنقّل في المنزل وسطح المكتب والمستندات والتنزيلات. انقر مرتين لفتح مجلد أو ملف. البحث يرشّح المجلد الحالي، وزر رجوع يعود في سجل التنقل.
4. اختر **مجلد جديد** لإنشاء مجلد حقيقي. المتصفح الحالي يعرض قائمة، ولا يقدّم جميع وظائف Finder مثل الوسوم والمعاينة وعرض الأعمدة.
5. اختر ملفًا ثم **نقل إلى سلة المهملات**. افتح السلة من آخر شريط التطبيقات، وحدد الملف ثم **استعادة**. لا تستبدل الاستعادة ملفًا موجودًا، ولا يوجد زر حذف نهائي للسلة.
6. افتح محرر النصوص أو الطرفية من الشريط. هما تطبيقان حقيقيان للينكس؛ تبقى بنية قوائمهما الأصلية رغم المظهر المشترك.
7. افتح البحث عبر رمز التطبيقات أو Super+Space؛ استخدم Enter للفتح وEsc للإغلاق.

النقاط الصغيرة أسفل الأيقونات تشير إلى التطبيقات المفتوحة، ولها مساحة مستقلة حتى لا تُزيح مركز الأيقونة.

## حفظ العمل والإيقاف

```sh
docker stop vantah-current
docker start vantah-current
docker cp vantah-current:/home/sandbox/Documents ./vantah-documents-backup
```

الإيقاف وإعادة التشغيل يحفظان الملفات. انسخ المجلدات المهمة قبل إزالة الحاوية؛ إزالة الحاوية تحذف ملفاتها الداخلية. المُثبّت لا يزيل الحاويات تلقائيًا.

## حل المشكلات

- إذا انقطع noVNC، انتظر بدء سطح المكتب ثم أعد تحميل الصفحة. افحص `docker logs` وملف `/tmp/desktop.log` داخل الحاوية.
- إذا تعذّرت السلة، تأكد من تثبيت `gvfs` وتشغيل خدماته في جلسة DBus الخاصة بسطح المكتب. ملفات التثبيت الحالية تتضمنه.
- إذا امتلأ القرص أثناء البناء، أوقف البناء ووفّر مساحة دون حذف حاويات أو وحدات تخزين لا تخص المشروع.
- إذا ظهرت العربية ولم تستطع الكتابة بها، أضف تخطيطًا عربيًا في إعدادات لوحة مفاتيح لينكس. اختُبرت أسماء الملفات العربية والبحث عنها ونقلها للسلة واستعادتها.
