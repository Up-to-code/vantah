# vAntah TikTok videos

Two 15-second portrait exports of the real desktop walkthrough:

- [English video](vantah-tiktok-en.mp4) · [SRT](vantah-tiktok-en.srt) · [WebVTT](vantah-tiktok-en.vtt)
- [Arabic video](vantah-tiktok-ar.mp4) · [SRT](vantah-tiktok-ar.srt) · [WebVTT](vantah-tiktok-ar.vtt)

Both exports are 1080×1920, 30 fps, H.264 with AAC stereo music and burned-in captions. The complete desktop stays visible within the portrait layout. The underlying recording is sped up; see [recording provenance](../recording.md). Captions describe the demonstrated actions; they are not a speech transcript. There is no narration.

The soundtrack, `vantah-original-music.wav`, is an original synthesized ambient loop generated by the included script: A-minor tones, plucked chimes and a soft pulse. It uses no third-party samples, recordings, or borrowed songs. It is provided under this repository's license.

## Rebuild

From the repository root, create a Python virtual environment, then install `Pillow`, `arabic-reshaper`, and `python-bidi`. Install FFmpeg separately, then run:

```sh
python scripts/build-social-videos.py
```

The default fonts are local macOS fonts used only to render text; font files are not distributed. On Linux, supply installed Latin and Arabic font paths:

```sh
python scripts/build-social-videos.py \
  --font /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf \
  --arabic-font /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf
```

Arabic captions are shaped and ordered for display. Subtitle sidecars contain logical Unicode text for subtitle players. The English/Arabic downloads are ready to upload.
